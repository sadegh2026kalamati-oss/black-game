BLACK GAME — نسخه اولیه سایت معرفی بازی‌های کامپیوتر

اجرا:
1) فایل ZIP را استخراج کنید.
2) روی index.html دوبار کلیک کنید تا سایت در مرورگر باز شود.
3) برای تغییر محتوا، فایل index.html و برای ظاهر و رفتار، style.css و script.js را ویرایش کنید.

امکانات فعلی:
- طراحی فارسی و راست‌چین، واکنش‌گرا
- جست‌وجوی بازی و فیلتر دسته‌بندی
- پنجره جزئیات بازی
- پیوند به صفحات رسمی بازی‌ها در Steam
- توضیحات متا و عنوان صفحه برای شروع SEO

نکته‌های انتشار:
- این نسخه فعلاً نمایشی و استاتیک است؛ پنل مدیریت، حساب کاربری، دیتابیس و آپلود بازی ندارد.
- لینک‌ها به صفحات رسمی فروشگاه‌ها می‌روند، نه فایل‌های غیرمجاز.
- برای انتشار عمومی به دامنه و هاست نیاز دارید. پس از خرید دامنه، HTTPS، sitemap.xml، robots.txt و Google Search Console را تنظیم کنید.
- فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ برای استفاده آفلاین می‌توانید فایل فونت را محلی اضافه کنید.
- مشخصات سیستم و حجم هر بازی را قبل از انتشار از منبع رسمی همان نسخه بررسی و تکمیل کنید.
